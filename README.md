# Green Log 

観葉植物の成長や水やりを記録・管理するWebアプリケーションです。

Pythonの学習を兼ねて個人開発を行っています。
現在はWebアプリケーションに加え、マイコンとセンサーを利用したIoT機能の開発にも取り組んでいます。

## 制作目的

- 観葉植物の水やりや成長を記録・管理する
- Pythonを使用したWebアプリケーション開発を学ぶ
- センサーを利用した環境測定とデータ通信を学ぶ
- 開発を通じて問題解決能力を身につける

## 実装済みの機能

### Webアプリケーション

- 複数の観葉植物の管理
- 植物の高さ・成長記録
- 水やり記録
- JSONファイルによるデータの保存
- ブラウザ上での記録の確認

### IoT・組み込み開発

- I2C通信によるセンサー制御
- 温度・湿度・気圧の取得
- 液晶画面への測定値の表示
- 5秒ごとの測定値更新
- ボタン操作による音声再生
- Wi-Fi接続テスト
