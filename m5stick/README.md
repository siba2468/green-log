# M5StickS3 音声通知機能

## 概要
M5StickS3とMicroPythonを使用した音声通知機能の試作です。

本体のボタンを押すと、保存したWAVファイルをスピーカーから再生します。

## 使用技術
- Python（MicroPython）
- M5StickS3
- UIFlow2
- VOICEVOX

## 実装済み機能
- ボタン操作の検出
- WAVファイルの再生
- スピーカーの音量設定
