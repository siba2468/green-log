## 1. I2C通信

マイコンとセンサー間でデータをやり取りする通信方式。

| 用語 | 意味 |
|---|---|
| SDA | データをやり取りする信号線 |
| SCL | 通信のタイミングを合わせる信号線 |
| GPIO | 汎用入出力端子 |
| ピンマップ | 各端子の役割を示した資料 |
| I2Cアドレス | 通信相手を識別する番号 |
| 周波数 | 通信のクロック速度に関わる数値 |

### 今回の設定

- SDA：GPIO9
- SCL：GPIO10
- 周波数：100kHz

公式資料のサンプルコードを参考に、
使用機器のピンマップに合わせて変更した。

## 2. センサーの認識と測定

I2Cスキャン結果：[68, 112]

| アドレス | センサー | 測定項目 |
|---|---|---|
| 0x44 | SHT30 | 温度・湿度 |
| 0x70 | QMP6988 | 気圧 |

ライブラリを利用することで、
複雑な通信処理を一から実装せずに
測定値を取得できることを学んだ。

- read_temperature()
- read_humidity()
- read_pressure()

## 4. Wi-Fiとネットワーク

| 用語 | 意味 |
|---|---|
| SSID | Wi-Fiのネットワーク名 |
| WPA2・WPA3 | Wi-Fiのセキュリティ規格 |
| 2.4GHz・5GHz | Wi-Fiの周波数帯 |
| IPアドレス | ネットワーク上の機器を識別する番号 |
| ゲストWi-Fi | 通常とは別に用意するWi-Fi |

セキュリティを考慮してゲストWi-Fiを利用した。
ネットワークの分離状態は今後確認する。

## 5. MicroPythonによるWi-Fi接続

networkモジュールを利用した。

| メソッド・定数 | 役割 |
|---|---|
| STA_IF | Wi-Fiに接続する端末としてのモード |
| active() | Wi-Fi機能の有効化・無効化 |
| connect() | Wi-Fiへの接続 |
| isconnected() | 接続状態の確認 |
| ifconfig() | IPアドレスなどの取得 |

### 発生した問題と解決方法

- 現象：M5StickS3がWi-Fiに接続できない
- 検証：スマートフォンでは接続できることを確認
- 原因：SSIDの入力ミス
- 解決：SSIDを修正して接続成功

複雑な原因を疑う前に、基本的な設定を
確認することの重要性を学んだ。

パスワードなどの認証情報はGitHubに公開しない。
